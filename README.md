# 📊 Análise de Lojas – Alura Store

Este projeto tem como objetivo analisar os dados de 4 lojas da rede fictícia Alura Store e recomendar qual delas deve ser vendida, com base em:

- Faturamento total
- Vendas por categoria
- Avaliação média dos clientes
- Produtos mais e menos vendidos
- Frete médio por loja

## ✅ Conclusão

A **Loja 2** foi identificada como a de pior desempenho geral e é a recomendada para venda, devido a:

- Menor faturamento
- Piores avaliações
- Mix de produtos fraco
- Frete mais caro

## 🛠️ Tecnologias

- Python
- Pandas
- Matplotlib

## ▶️ Como rodar

1. Clone este repositório
2. Abra o notebook no Jupyter ou Google Colab
3. Execute as células e visualize os gráficos
